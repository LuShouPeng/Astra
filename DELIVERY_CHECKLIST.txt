功能清单
================================================================================

✅ Git Commit
   - 提交所有更改
   - 提交指定文件
   - 自定义作者信息
   - 返回 commit ID 和分支

✅ Git Checkout
   - 切换到现有分支
   - 创建新分支并切换
   - 支持 detached HEAD

✅ Git Merge
   - Fast-forward 合并
   - 普通合并（创建合并提交）
   - 冲突检测和报告
   - Up-to-date 检测

✅ Git Reset
   - Soft reset（保留暂存和工作目录）
   - Mixed reset（保留工作目录）
   - Hard reset（丢弃所有更改）
   - 重置到 HEAD 或指定 commit

✅ Git Worktree 管理
   - 列出所有 worktree
   - 创建新 worktree
   - 删除 worktree
   - 自动目录管理

✅ UI 组件
   - 完整的操作界面

   - 错误处理和提示

已知问题和注意事项
================================================================================

1. Rust 工具链安装
   - 需要管理员权限
   - 安装后必须重启终端
   - 首次构建需要较长时间

2. Node.js 版本
   - 当前版本: 20.18.1
   - 推荐版本: 20.19+ 或 22.12+
   - Vite 会显示警告但不影响功能

3. Visual Studio Build Tools
   - Windows 上编译 git2 可能需要
   - 如遇到编译错误请安装

4. 首次构建时间
   - Rust 代码首次编译: 5-15 分钟
   - 后续增量编译: 30 秒 - 2 分钟
   - 这是正常现象
