================================================================================
如何安装 Rust - 三种方法
================================================================================

⚠️ 重要提示：Rust 需要 Visual Studio C++ 组件才能在 Windows 上工作

================================================================================
方法 1：自动安装（推荐，最简单）
================================================================================

步骤：
1. 双击运行文件：install-rust-auto.bat
2. 按照提示操作
3. 如果需要 Visual Studio，脚本会自动处理
4. 等待安装完成（20-40 分钟）
5. 关闭终端，打开新终端
6. 验证：cargo --version
7. 启动项目：双击 dev.bat

优点：
✅ 完全自动化
✅ 自动安装所有依赖
✅ 适合新手

缺点：
⚠️ 需要下载约 2-3 GB
⚠️ 安装时间较长

================================================================================
方法 2：分步手动安装（推荐，更可控）
================================================================================

第一步：安装 Visual Studio Build Tools
--------------------------------------
1. 打开浏览器访问：
   https://visualstudio.microsoft.com/zh-hans/downloads/

2. 向下滚动找到"Tools for Visual Studio"

3. 下载"Build Tools for Visual Studio 2022"

4. 运行安装程序，勾选：
   ✅ Desktop development with C++（使用 C++ 的桌面开发）
   ✅ Windows 10 SDK

5. 点击安装，等待完成（10-20 分钟）

第二步：安装 Rust
-----------------
1. 双击运行：rustup-init.exe

2. 在命令行窗口中输入：1
   然后按回车键

3. 等待安装完成（5-10 分钟）

4. 关闭当前终端

5. 打开新终端，运行：
   cargo --version

6. 如果显示版本号，说明成功！

7. 启动项目：
   双击 dev.bat

优点：
✅ 可以选择安装内容
✅ 更好地控制安装过程
✅ 安装包可以离线使用

缺点：
⚠️ 需要手动操作多个步骤

================================================================================
方法 3：使用完整的 Visual Studio（适合专业开发者）
================================================================================

第一步：安装 Visual Studio Community
------------------------------------
1. 访问：https://visualstudio.microsoft.com/zh-hans/downloads/

2. 下载"Visual Studio Community 2022"（免费）

3. 运行安装程序

4. 在工作负载选择界面，勾选：
   ✅ 使用 C++ 的桌面开发

5. 点击安装，等待完成（15-30 分钟）

第二步：安装 Rust
-----------------
（同方法 2 的第二步）

优点：
✅ 最完整的开发环境
✅ 包含调试器和其他工具
✅ 适合长期开发

缺点：
⚠️ 安装包最大（2-3 GB）
⚠️ 安装时间最长

================================================================================
验证安装是否成功
================================================================================

在新的终端窗口中运行：

cargo --version

如果看到类似以下输出，说明安装成功：
cargo 1.xx.x (xxxxx 2024-xx-xx)

如果提示"cargo: command not found"：
1. 确保已关闭旧终端，打开新终端
2. 检查是否已完成 Rust 安装
3. 重启计算机

================================================================================
安装完成后的下一步
================================================================================

1. 验证 Rust 安装
   cargo --version

2. 启动开发模式
   双击：dev.bat
   或运行：npm run tauri dev

3. 首次启动需要 5-15 分钟编译 Rust 代码
   请耐心等待...

4. 应用窗口会自动打开

5. 测试 Git 操作功能
   - 添加本地 Git 项目
   - 进入 Changes 页面
   - 测试 Commit、Checkout、Merge 等功能

================================================================================
常见问题
================================================================================

Q: 如何知道选择哪种方法？
A: 如果你不确定，选择方法 1（自动安装）

Q: 安装需要多长时间？
A: 首次安装通常需要 30-60 分钟（包括下载时间）

Q: 需要多少磁盘空间？
A: 至少需要 5-10 GB 的可用空间

Q: 可以取消安装吗？
A: 可以，但建议完成安装才能运行项目

Q: 安装失败怎么办？
A: 查看 RUST_INSTALLATION_GUIDE.md 中的详细故障排除指南
