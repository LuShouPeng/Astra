实现的功能
================================================================================

1. Git Commit - 提交更改到仓库
   - 支持全部或指定文件
   - 自定义作者信息
   
2. Git Checkout - 切换和创建分支
   - 切换现有分支
   - 创建新分支
   
3. Git Merge - 合并分支
   - Fast-forward 和普通合并
   - 冲突检测和报告
   
4. Git Reset - 重置工作目录
   - Soft/Mixed/Hard 三种模式
   - 重置到 HEAD 或指定提交
   
5. Worktree 管理 - 并行开发
   - 列出、创建、删除 worktree

================================================================================
常见问题
================================================================================

Q: "cargo: command not found"
A: 运行 rustup-init.exe，然后重启终端

Q: Git2 编译错误
A: 安装 Visual Studio Build Tools
   https://visualstudio.microsoft.com/downloads/

Q: 构建速度慢
A: 首次构建需要 5-15 分钟，这是正常的
   后续构建会更快

Q: Node.js 版本警告
A: 升级到 Node.js 20.19+ 或 22.12+
   https://nodejs.org/
