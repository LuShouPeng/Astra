# 项目状态记录体系

跟踪「真实 Agent 集成」开发进度，对齐 [`../real-agent-integration.md`](../real-agent-integration.md) 的里程碑。

## 文件

| 文件 | 作用 | 更新方式 |
|------|------|---------|
| [`STATUS.md`](./STATUS.md) | **当前状态**，唯一事实源 | 每个里程碑**覆盖更新** |
| [`history/`](./history/) | **历史快照**，逐里程碑冻结 | 只新增，**永不修改** |

## 每完成一个里程碑的更新流程

1. 把 `STATUS.md` 的当前内容**复制**到 `history/M{n}-{slug}.md`，在顶部标注该里程碑完成日期与 commit/tag，此后冻结不再改。
2. 更新 `STATUS.md`：里程碑总览、六项能力状态、已实现/需修改/未开发三张表、契约现状，改到反映最新真实状态。
3. 更新顶部元信息（日期、当前里程碑、最新 commit、测试计数）。
4. 随里程碑代码一起提交，commit message 带上状态更新。

## 图例

- ✅ 已实现：功能完整、连到真实后端、可用
- 🔧 需修改：已存在但为 mock/占位，须改造
- ❌ 未开发：目标功能，代码中完全不存在

## 原则

- **代码验证优先**：状态判断必须基于实际读代码，不凭记忆或计划推断。
- **历史不可变**：`history/` 里的快照是某一时点的真相，后续里程碑不回改，便于对比演进。
